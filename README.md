# ⚡ J.A.R.V.I.S. - Hybrid Voice AI Assistant

An open-source personal AI voice assistant that operates seamlessly in both **Offline** and **Online** modes.

## ✨ Features
- **Offline Operations:** System time, date checking, opening apps, and local controls without active internet.
- **Online Intelligence:** Powered by Google Gemini AI for contextual answering and conversations.
- **Continuous Wake-Word Detection:** Listens silently in standby mode for `"Wake up Jarvis"`.
- **Pure Python:** No complex binary compilation required.
